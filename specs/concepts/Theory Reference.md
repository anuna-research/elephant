# Theory Reference

A theory reference identifies an Elephant theory and optionally one signed statement within it.
It contains stable IDs rather than a machine's local alias.
Its [[URI Profile]] gives it a portable text representation.
The reference grants no membership, carries no keys, and promises no network location.

A sentence reference identifies an utterance, not the truth of that utterance.
A [[Result Report]] provides an utterance about a conclusion that changes over time.
