# Result Report

A result report is a destination-bound signed statement about a selected result observed in another theory.
It identifies the reporter, source theory, literal, reported proof tag, observation time, and expiry.
The signature authenticates the reporter's statement; it does not independently prove the source computation.

A [[Theory Reference]] can cite the report as a historical statement.
Expiry ends its eligibility as a current premise without deleting that history or asserting the opposite result.
The receiving theory's rules decide whether a report supports a local conclusion.
